## ASCII Banner FIGlet-Style Text Generator

Renders A-Z and 0-9 text in five fully JS-implemented ASCII art fonts: Block (# characters, 5 rows), Thin (|/- characters, 4 rows), Shadow (Block with dot-shadow effect), Big (* characters, 6 rows), and Banner (= characters, 6 rows). Includes a copy-to-clipboard button and live character count.

**Tech:** Vanilla JS, Tailwind CSS CDN, hand-crafted pixel glyph maps for each character in all 5 fonts.

**How to use:** Type text (up to 20 characters) in the input field, select a font tab to switch styles, and click "Copy to Clipboard" to copy the ASCII art. Non-alphanumeric characters are automatically removed.
